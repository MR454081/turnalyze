# AI Detector Training Data

## Dataset Format

CSV files with two columns:

| Column | Description |
|--------|-------------|
| `text` | The text sample to classify |
| `label` | `0` = HUMAN, `1` = AI |

## Files

| File | Purpose |
|------|---------|
| `train.csv` | Training samples |
| `validation.csv` | Validation samples (used for early stopping and calibration) |
| `test.csv` | Held-out test samples |
| `demo/demo_samples.csv` | Small demo samples for pipeline testing only |

## Split Logic

To prevent data leakage:

- **Split by source/document**, not by random paragraph.
- The same original document must not appear in both training and test sets.
- The same AI generation prompt should not create leakage between splits.

## Example Row

```csv
text,label
"The present study investigates socioeconomic status and educational attainment among adolescents.",0
"Artificial intelligence is transforming the way we live and work.",1
```

## Requirements

- Do NOT include fake/random placeholder text in the real training dataset.
- Demo data is clearly separated under `demo/`.
- Human samples should be genuine human academic writing.
- AI samples should be generated by modern LLMs (GPT-4, Claude, Gemini, etc.).
